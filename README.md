# Swift Book

Swift Book is a browser-based PDF reader and annotation workspace. It supports multi-document tabs, page layouts, highlights, drawing, notes, a book library, custom books, and exporting.

## Run Locally

**Prerequisites:** Node.js


1. Install dependencies: `npm install`
2. Start the app: `npm run dev`
3. Open `http://localhost:3000`

No API key is required.

## Publish to GitHub Pages

Run `npm run lint` and `npm test`, commit the reviewed changes on `main`, then run `npm run deploy`.
The deploy command builds the committed source and pushes both `main` and the generated static files on `gh-pages`.

The public source commit can be checked at [build-info.json](https://hgntrancontact-glitch.github.io/swiftbook/build-info.json).
Deployment history is in the [gh-pages commits](https://github.com/hgntrancontact-glitch/swiftbook/commits/gh-pages/).
